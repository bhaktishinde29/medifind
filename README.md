


# medifind
Medicine search web app using Spring Boot &amp; MySQL.
Medifind is a web-based application designed to help users search for medicines and get detailed information such as price, availability, company name, ingredients, and related diseases.
The project is built using Java (Spring Boot) for the backend and provides a simple, user-friendly interface for efficient medicine loo

🚀 Features:
🔍 Search medicines by name
💰 View price and availability
🏢 Get company/manufacturer details
🧪 Check ingredients of medicines
🩺 Know diseases related to medicines
📋 Display complete medicine details in a structured format
➕ Add new medicines to the database (Admin feature)

🛠️ Tech Stack
Backend: Java, Spring Boot
Frontend: HTML, CSS, Thymeleaf
Database: MySQL
Build Tool: Maven
